# Crust Rush — native build (Godot 4.7)

The native version of the Crust Rush web game, for running straight on the iPhone's GPU (Metal) and on PC.

- **Play on PC:** install Godot 4.7.2 (free, godotengine.org), open this folder's `project.godot`, press Play (F5).
- **iPhone build:** every push to this branch builds an unsigned `CrustRush.ipa` on GitHub (Actions → "iPhone build" → Artifacts).
  Install it from Windows with a sideloading tool and your Apple ID (free accounts: re-install every 7 days).

The web game lives on the `main` branch and is unaffected by this branch.
